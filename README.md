Built for the [make.fun "One Line, One Laugh" bounty](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) — a program that writes one funny line to `/output/entry.txt`. Join make.fun with referral code `qgn48q27`: https://make.fun/r/qgn48q27

> I asked the universe for a sign. It sent me a CAPTCHA.

## Run

```sh
node main.ts
```

No build step, no network, no dependencies — plain Node 22. Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (or `/output` when unset) and exits 0.
